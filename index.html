A small, fast launcher for Minecraft: Java Edition

Eagler Java Launcher is a free, open-source Windows app. It signs you in with your own Microsoft account, downloads the official game files from Mojang, and starts the game with performance mods.

Download for Windows View the source

Features

Microsoft account sign-in

Standard Microsoft device-code sign-in (microsoft.com/link). The launcher never sees your password.

Official game files

Minecraft, its libraries and the Java runtime are downloaded from Mojang's own servers and checked by SHA-1.

Performance

Optional Fabric performance mods (Sodium, Lithium, FerriteCore…) from Modrinth and tuned Java settings.

Servers and resource packs

Manages the multiplayer server list and installs resource packs from a link or a .zip file.

How sign-in works

  1. The launcher asks Microsoft for a short code and opens microsoft.com/link.
  2. You sign in on Microsoft's page with the account that owns Minecraft: Java Edition.
  3. The launcher exchanges the result with Xbox Live and Minecraft services to get your profile and a game token.
  4. Tokens are stored encrypted for your Windows user (DPAPI) and only sent to Microsoft and Mojang.

You need to own Minecraft: Java Edition. An optional username-only mode exists for offline-mode servers; it cannot join online-mode servers and does not use Minecraft services.

Requirements

SystemWindows 10 or 11 (64-bit). No install: one .exe using the built-in .NET Framework 4.8.
AccountA Microsoft account that owns Minecraft: Java Edition.
DiskAbout 1 GB for the game, Java runtime and assets.
